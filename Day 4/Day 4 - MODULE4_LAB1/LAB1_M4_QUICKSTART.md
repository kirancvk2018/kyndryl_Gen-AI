# Quickstart: Text-to-Speech Assistant for IT Infrastructure

This guide is for participants with basic computer skills. You do not need to write any Python code. You will install a few tools, add your OpenAI API key, and run the notebook one cell at a time.

**What you need before you start**

- A computer with Python 3.9 or newer installed (check with `python --version` in a terminal).
- A valid **OpenAI API key** that can use the Text-to-Speech API.
- An **internet connection**. Live audio is generated by the OpenAI service, so the lab cannot create audio without it.

---

### Step 1: Extract the project ZIP

Right-click `MODULE4_LAB1_Text_to_Speech_Assistant.zip` and choose **Extract All**. Choose a folder you can find again, such as your Documents folder.

### Step 2: Open the extracted folder in VS Code or Jupyter

Open the folder named `MODULE4_LAB1`:

- In **VS Code**: choose **File > Open Folder** and select `MODULE4_LAB1`.
- Or simply keep the folder open in **File Explorer** so you can find it in the next steps.

### Step 3: Open the terminal

- In **VS Code**: choose **Terminal > New Terminal**. The terminal opens in the project folder.
- On **Windows**: click the address bar of the `MODULE4_LAB1` folder in File Explorer, type `powershell`, and press Enter.
- On **macOS**: open **Terminal**, type `cd ` (with a space), drag the `MODULE4_LAB1` folder into the window, and press Enter.

### Step 4: Install dependencies

In the terminal, type the following command and press Enter:

```
pip install -r lab1_m4_requirements.txt
```

Wait until the installation finishes without red error messages.

### Step 5: Configure the OpenAI API key as an environment variable

Your API key is a secret. Do not paste it into the notebook, into an email or into a shared document.

Use the command for your system in the **same terminal** you will use in Step 6.

- **Windows PowerShell:**

  ```
  $env:OPENAI_API_KEY = "paste-your-key-here"
  ```

- **macOS or Linux:**

  ```
  export OPENAI_API_KEY="paste-your-key-here"
  ```

Replace `paste-your-key-here` with your key, keep the quotation marks, and press Enter. The key is kept only for this terminal session.

*Alternative:* create a file named `.env` in the `MODULE4_LAB1` folder that contains one line: `OPENAI_API_KEY=paste-your-key-here`. The notebook reads this file automatically.

### Step 6: Start Jupyter

In the same terminal, type the following command and press Enter:

```
jupyter notebook
```

Your web browser opens a page that lists the files in the folder. If it does not open, copy the address shown in the terminal (it starts with `http://localhost`) into your browser.

### Step 7: Open the notebook

In the browser page, click **module4_lab1_text_to_speech.ipynb**.

### Step 8: Execute the cells in order

- Click a cell, then press **Shift + Enter** to run it and move to the next cell.
- Run the cells **from the top**. Do not skip cells.
- Read the grey explanation cells. They describe what the next code cell does.
- Cells with a short comment such as *Change this* can be edited. Change only the value after the `=` sign, for example `SELECTED_VOICE = 'alloy'` to `SELECTED_VOICE = 'nova'`.
- If a cell shows a red error, read the message. It explains what to fix. Then run the cell again. To start over, choose **Kernel > Restart & Run All** from the menu.

**Tip:** the first audio cells take a few seconds because the audio is generated online.

### Step 9: Listen to the generated audio

Each example shows an audio player under the code. Click the play button to listen. Set `PLAY_AUDIO = False` in Cell 3 if you do not want the players to appear.

### Step 10: Review `audio_output/` and `tts_logs/`

- **`audio_output/`** contains the MP3 files. You can open them in any media player.
- **`tts_logs/audio_generation_log.csv`** is a log of every file. Open it with Excel or Notepad. It shows the time, scenario, voice, speed, model and file name for each file.

---

**Important**

- A **valid OpenAI API key** and an **internet connection** are required to generate live audio.
- Without a key, the notebook still opens and the setup cells run, but the audio cells stop with a message that explains how to add the key.
- Creating audio uses your OpenAI account. Run only the examples you need.
