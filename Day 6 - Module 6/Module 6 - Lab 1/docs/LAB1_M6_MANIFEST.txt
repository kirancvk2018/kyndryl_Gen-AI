================================================================================
TROUBLESHOOTING BY FILE
================================================================================

If the notebook will not open:
  -> pip install jupyter
  -> Check the file is in this folder

If the API key fails (401):
  -> Check the OPENAI_API_KEY line in .env
  -> Restart the kernel after editing .env

If the model is not found (404):
  -> Set OPENAI_MODEL=gpt-4o-mini in .env, then restart the kernel

If sample data will not load:
  -> Run the notebook from this folder so the file paths resolve
