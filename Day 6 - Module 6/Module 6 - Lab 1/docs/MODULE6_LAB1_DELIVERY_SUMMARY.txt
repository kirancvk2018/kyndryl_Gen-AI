================================================================================
WHAT CHANGED IN VERSION 2.0
================================================================================

- Use case: IT incident examples replaced with routine corporate operations
  (shift handovers, helpdesk ticket triage, meeting action items, status emails).
- Code: plain functions only. No classes and no Pydantic models.
- Requirements: pydantic removed. LangChain versions are unchanged
  (langchain>=1.0.0, langchain-openai>=1.0.0).
- Model: gpt-4o-mini (default in code and in the .env template).
- Settings: the notebook reads OPENAI_MODEL, LLM_TEMPERATURE and MAX_TOKENS
  from .env, so the documentation and the code agree.
- Sample data: data/sample_tickets.json, data/sample_shift_notes.txt and
  data/sample_meeting_notes.txt replace the IT incident, alert and log samples.
